## 1. 数据安全（最高优先级）

- ✅ 打开 GBK / UTF-16 / BOM / CR-only 文件后保存，字节级还原（fixture 语料）
- ✅ 有损解码文件保存前二次确认，取消则不写盘
- ✅ 原子保存（临时文件 + rename），保存失败不损坏原文件
- ✅ 外部修改检测：保存前 mtime/size 比对，冲突三选一
- ✅ 文件监听：干净标签静默重载；脏标签弹「保留我的修改 / 加载磁盘版本 / 稍后处理」
- ✅ 关闭窗口：脏标签逐个询问（保存 / 不保存 / 取消）
- ✅ 混合换行：状态栏徽标 + 保存前确认统一
- ✅ 会话恢复时失效文件跳过并一次性提示，随后从会话剔除
- 👁 断网/只读目录/磁盘满 三个异常场景下的报错文案与不丢数据

## 3. 大文件

- ✅ 分级：≤5 MB 全功能；5–20 MB 简化装饰；20–100 MB 只读虚拟滚动；>100 MB 明确拒绝
- ✅ 只读预览首屏 400 行、滚动按需取数，窗口滚动条与行号正确
- 👁 20 MB 文本在 L1 模式下的输入延迟（目标 P95 ≤ 16 ms，见 perf.md §7）

## 5. 安装与分发

- [ ] 干净机器（无管理员权限）安装冒烟：安装 → 打开文档 → 编辑 → 保存 → 退出 → 卸载
- [ ] MSI 与 NSIS 都能升级覆盖安装

## 6. 已知限制（发布说明需照录）

- 切换标签会重置该标签的撤销历史
- 脏标记只增不减（撤销回保存点仍显示未保存）
- 20–100 MB 文件只读，暂不支持编辑保存；>100 MB 直接拒绝
- 混合换行保存时统一为主导 EOL（保存前确认）
- 大文件只读预览不支持 UTF-16 编码
- Markdown 预览高亮只覆盖 10 种常用语言；切换预览会重置该标签撤销历史；导出会覆盖同名 `.html`
- 预览/导出通过 Rust 命令读取本地图片并内联为 data URI（单张 ≤32 MB），不再使用 asset 协议
- 无自动更新、无便携版（M4）

## 7. 发布动作

1. 归档 CHANGELOG、更新三处版本号、提交 `chore: release v0.1.0`
2. `pnpm tauri build`，记录产物 SHA256
3. 打 tag `v0.1.0`，Release Notes 按 CHANGELOG 摘要 + 已知限制
4. 上传 MSI/NSIS，分别在 win10 / win11 各装一次做最终验证
