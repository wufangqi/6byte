## 2. P0 细则（已全部完成）

### ✅ T01 有损解码保存前二次确认
- **现状**：`codec.rs` 在严格 UTF-8 失败后用 chardetng 猜测，非法字节替换为 `U+FFFD` 并置 `meta.lossy = true`；原先 `write_file` 不检查 `lossy`，保存即把原字节永久改写。
- **已完成**：
  1. Rust `write_file` 新增 `allow_lossy` 参数，`lossy && !allow_lossy` 直接拒绝；
  2. 前端保存前弹「编码有损，保存会改写原数据」，取消即中止，确认后按原编码写回并把 `lossy` 置回 false；
  3. 状态栏有损告警保留。
- **验收**：`lossy_save_requires_explicit_permission` 单测通过——拒绝时磁盘无写入，显式授权后可写。

### ✅ T02 脏标签 / 关窗拦截
- **已完成**：新增通用弹窗（`features/Dialog.tsx`：Esc 取消、Enter 取主操作、点遮罩取消）；关闭标签、Ctrl+W、中键关闭统一走「保存 / 不保存 / 取消」；窗口关闭改用 `onCloseRequested`，逐个处理脏标签，全部通过后才 `destroy()`；`capabilities/default.json` 增补 `core:window:allow-destroy`。
- **验收**：安装版发送 WM_CLOSE（无脏标签）→ 进程正常退出，证明拦截与 destroy 权限链路可用；脏标签三选一需人工点验。

### ✅ T03 编辑热路径去 O(n)
- **已完成**：store 不再每键持有全文，改为 `markEdited(id, {lines, chars})`（O(1)）；新增 `editor/registry.ts` 登记活动 `EditorView`，保存时读取实时文本；编辑器卸载时回写快照并用 `version` 守卫，避免磁盘重载后被旧视图覆盖；状态栏改用 `doc.lines/doc.length`，删除每键 `split()` 与 `new Blob()`；会话持久化 500 ms 防抖，最近文件仅在引用变化时写盘。
- **验收**：类型检查通过、构建通过。输入延迟已于 2026-10-22 量化（第二十四批）：1000 行 L0 处理 P95 **5.6 ms**，10 MB / 19 MB L1 为 **3.0 ms / 2.7 ms**（预算 ≤16 ms）。

- **验收**：`stat_file_reports_size_and_mtime` 单测通过；三选一交互待人工点验。
